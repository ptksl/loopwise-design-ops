# Loopwise UI

The Loopwise Design System's tokens on shadcn (Radix version): Button, Tabs and Dialog, Light and Dark. Loopwise is a
self-initiated system by Prateek Singhal, built with Claude Code.

```bash
npm run dev
```

- `src/styles/loopwise.css`: tokens read from Figma, plus motion tokens that are only in code so far.
- `src/app/globals.css`: the bridge from shadcn's names to Loopwise tokens.
- `src/components/ui/`: the components.
- `DECISIONS.md`: what was kept, what was changed and why.
